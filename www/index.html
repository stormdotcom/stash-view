Getting started

Up and running in seconds

1
Install from Chrome Web Store

Click "Add to Chrome". No signup, no account — just the extension.

2
Click the toolbar icon

Navigate to any website and click the StashView icon in your Chrome toolbar. The popup opens instantly.

3
Inspect & edit

Browse storage tabs, click a key to expand its value, edit or delete entries, and filter by key name.

🔒

Your data never leaves your machine

StashView reads storage data from the current tab and displays it locally in the popup. There are no external network requests, no analytics, no crash reporting, no CDN scripts — nothing leaves your browser. Ever.
